# 🎨 IA Art Studio

Una aplicación de escritorio profesional creada en Python para generar flyers, pósters y arte conceptual utilizando Inteligencia Artificial.

![Demo de la App](demo.png)
*(Si subiste una imagen, asegúrate de que se llame demo.png)*

## ✨ Características
- **Generación Ilimitada:** Conexión directa a API de difusión estable (Pollinations).
- **Formatos Inteligentes:** Crea diseños para Instagram (Post/Story), YouTube o Pósters.
- **Ajuste Automático de Texto:** El sistema calcula el tamaño de fuente para que el título siempre quepa perfecto.
- **Diseño Profesional:** Interfaz moderna (Modo Oscuro) creada con CustomTkinter.
- **Sin Censura de Errores:** Sistema de codificación URL robusto (v9) para evitar bloqueos.
